# Проверка инструкции для жюри

Дата: 23 сентября 2026. Версия приложения: `137f4c3de8a899f256c6860009feb5ab505060f4` из `codex/api-ui`. Ветка `codex/jury-readme` добавляет README, этот протокол и иллюстрацию; код приложения не изменён.

## Среда и установка

- Ubuntu 24.04.3, x86_64, Python 3.12.14.
- Исходники получены через авторизованный GitHub API; содержимое всех 84 файлов сверено с Git blob SHA перед подготовкой документации. Это проверка содержимого репозитория, а не проверка GitHub-авторизации на устройстве жюри.
- Создано новое venv без системных Python-пакетов. При установке и запусках убран дополнительный `PYTHONPATH`.
- `python -m pip install ".[serve,dev]"` выполнен успешно. Зависимости приложения и тестовые зависимости установлены из `pyproject.toml`.
- `python -m pip check`: `No broken requirements found.`
- Дополнительно создано второе пустое окружение и установлено только `python -m pip install ".[serve]"`, ровно как в инструкции жюри, без `dev`, pytest и httpx. В нём повторены pip check и весь браузерный сценарий ниже, включая расчёт настоящих данных через импорт. Оба завершились успешно.
- Использован уже собранный `frontend/dist` из репозитория. Node.js для установки и работы приложения не использовался; браузерная автоматизация — отдельный проверочный инструмент.

Это чистое Python-окружение на подготовленной Linux-машине, а не переустановка операционной системы. Системные команды установки Python для Windows/macOS в этой среде выполнить нельзя.

## Расчёт предоставленных данных

В новом окружении выполнен пакетный запуск:

```bash
python -m moneygraph run --data /path/to/provided/data --out /path/to/results
```

`/path/to/...` здесь обозначает локальные пути проверочной среды. Готовые команды с относительными путями находятся в [README](../README.md).

Результат:

- полный расчёт: **2,346 секунды**, без установки и открытия браузера;
- 2 248 клиентов, 3 119 направленных связей, 4 840 операций, 81 исходный клиент;
- 105 сообществ; 2 248 строк клиентов и 30 строк топа;
- завершённый каталог результата и указатель `current.json`;
- обязательные три CSV и дополнительные артефакты снимка.

Исходные Parquet, готовый финансовый снимок и идентификаторы настоящих клиентов в этот коммит не включены. Время — один контрольный замер, не бенчмарк разных машин и не показатель качества AML-решений.

## Автоматические проверки

После расчёта заданы `MONEYGRAPH_DATA_DIR`, `MONEYGRAPH_API_TESTS=1` и `MONEYGRAPH_SNAPSHOT_DIR` с путями настоящего набора и завершённого снимка. Выполнен `python -m pytest -q`.

```text
165 passed, 1 warning, 36 subtests passed in 27.16s
```

Пропущенных тестов в этом прогоне нет. Проверены загрузка и сверка денег, графовые признаки, пути, роли и приоритет, снимки, дневная активность, API и импорты. Интеграционные проверки включают настоящий HTTP-запуск через CLI `--serve`, соответствие карточек файловому снимку и побайтовое совпадение обязательных CSV-экспортов.

Единственное предупреждение — `StarletteDeprecationWarning` об использовании `httpx` в тестовом клиенте. Оно относится к будущей совместимости тестового инструментария; тесты и запуск приложения завершились успешно. Зависимости не менялись ради скрытия предупреждения.

## Браузер

Chromium 134, автоматизированный headless-прогон через Playwright. Сервер запущен отдельным процессом на свободном локальном порту; обращения выполнены по HTTP.

Проверенная последовательность:

1. Запуск `python -m moneygraph.api --demo`, получение страницы и четырёх локальных frontend-ресурсов.
2. Отображение 24 синтетических клиентов, очереди, графа и карточки.
3. Открытие сохранённой цепочки и возврат к сети.
4. Вкладки «По дням» и «Переводы», отсутствие сообщения об ошибке загрузки дневной активности.
5. Получение Excel через интерфейс: HTTP 200 и ZIP-сигнатура файла XLSX. Содержимое экспортов дополнительно проверяют тесты проекта.
6. Загрузка трёх настоящих Parquet кнопкой «Новые данные», расчёт и переключение на снимок с 2 248 клиентами без режима DEMO.
7. Необработанных ошибок JavaScript за сценарий не зарегистрировано.

[Иллюстрация README](images/demo-overview.png) снята **до загрузки настоящих данных**, на синтетическом демо. Визуально проверены её читаемость и отсутствие данных кейса. Этот прогон не заменяет пользовательское исследование и не проверяет все браузеры или все размеры экрана.

## Windows и macOS

Отдельно выполнен подбор всех бинарных runtime-зависимостей Python 3.12 через pip с параметрами `--dry-run --ignore-installed --only-binary=:all: --python-version 3.12 --implementation cp --abi cp312`. Проверены платформы:

| Платформа pip | Результат |
|---|---|
| `win_amd64` | Успешный подбор 22 пакетов |
| `macosx_12_0_arm64` | Успешный подбор 22 пакетов |
| `macosx_12_0_x86_64` | Успешный подбор 22 пакетов |

Это проверяет наличие совместимых бинарных пакетов, **не исполнение приложения на соответствующей ОС**. Нативный Windows-запуск и замер 8,563 секунды зафиксированы отдельно тимлидом в [docs/ui.md](ui.md); это не новый Windows-прогон автора данного протокола. Полный нативный macOS-прогон в этой проверке не выполнялся.

Инструкции README используют явный путь к Python виртуального окружения, поэтому не зависят от команды `python` в PATH, активации окружения или политики исполнения PowerShell. Для macOS указан официальный установщик Python как альтернатива проблемному Homebrew-окружению.
